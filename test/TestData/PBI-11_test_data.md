## 2. ข้อมูลการแจ้งเหตุทั่วไป (General Incident)

ข้อมูลที่ใช้ในการป้อนฟอร์มแจ้งเหตุการณ์ แบ่งตาม **"ประเภทปัญหา (Category)"** ที่มีให้เลือกในระบบ:

### 2.1 ประเภท: ปัญหาเส้นทาง (Happy Path หลัก)

- **ประเภทปัญหา:** ปัญหาเส้นทาง
- **หัวข้อ:** น้ำท่วมขังบนถนนเส้นหลัก
- **รายละเอียด:** ไม่สามารถเดินทางผ่านได้ เนื่องจากน้ำท่วมสูงกว่า 50 ซม.
- **ไฟล์แนบที่ใช้เทสขนาด/ประเภท:**
  - ปกติ (JPG): `accident.jpg`
  - ประเภทไฟล์ที่รองรับ (PDF): `document.pdf`

### 2.2 ประเภท: อุบัติเหตุ (Accident)

- **ประเภทปัญหา:** อุบัติเหตุ
- **หัวข้อ:** รถชนบนทางด่วน
- **รายละเอียด:** เฉี่ยวชนกับรถยนต์อีกคัน รอประกันมาเคลียร์

### 2.3 ประเภท: ปัญหารถยนต์ (Car Problem)

- **ประเภทปัญหา:** ปัญหารถยนต์
- **หัวข้อ:** ยางแตก
- **รายละเอียด:** ยางรั่วและแตกตรงมอเตอร์เวย์

### 2.4 ประเภท: อื่นๆ (Others)

- **ประเภทปัญหา:** อื่นๆ
- **หัวข้อ:** พบสัตว์เลี้ยงบนถนน
- **รายละเอียด:** มีสุนัขวิ่งตัดหน้าบนถนนหลวง

## 3. ข้อมูลสำหรับ Negative Test Cases (Validation Errors)

ข้อมูลเหล่านี้จงใจกรอกเพื่อให้เกิด Error หรือกดยืนยันเพื่อดู Validation Message ของระบบ:

- **Missing Image (แจ้งเหตุโดยไม่มีภาพ):**
  - _หัวข้อ:_ เครื่องยนต์ขัดข้อง
  - _รายละเอียด:_ รถสตาร์ทไม่ติด รอกู้ภัยมาช่วยเหลือ
  - _ผลที่คาดหวัง:_ บันทึกสำเร็จ (รูปเป็นออปชัน เสริม)
- **Missing Location (แจ้งเหตุโดยไม่มีพิกัด):**
  - _หัวข้อ:_ ถนนซ่อม
  - _รายละเอียด:_ เทยางมะตอยใหม่
  - _ผลที่คาดหวัง:_ บันทึกสำเร็จ (Location เป็นออปชัน เสริม)
- **Invalid File Type (ห้ามอัปโหลด .exe):**
  - อัปโหลดไฟล์ `file.exe`
  - _ผลที่คาดหวัง:_ อัปโหลดไม่ได้ / แสดงข้อผิดพลาดว่าไม่รองรับนามสกุลไฟล์ชนิดนี้
- **Oversized File (ห้ามอัปโหลดเกิน 50MB):**
  - อัปโหลดไฟล์ขนาดยักษ์ (จำลองด้วย `oversize.txt` สมมติฐานว่าขนาดเกิน)
  - _ผลที่คาดหวัง:_ Frontend แสดง Alert แจ้งเตือนว่า "ไฟล์ต้องไม่เกิน 50MB"
- **Missing Basic Info (ไม่กรอกข้อมูลบังคับเลย):**
  - เว้นว่างชื่อหัวข้อและรายละเอียด แล้วกด "รายงานเหตุการณ์"
  - _ผลที่คาดหวัง:_ หน้าต่าง Alert แจ้งเตือน "กรุณากรอกข้อมูลให้ครบถ้วน"

## 5. ข้อมูลการทดสอบระดับความเร่งด่วน (Category Priority Mapping)

ทดสอบการทำงานในการจับคู่ระหว่างประเภทปัญหา (Category) และระดับความช่วยเหลือ (Priority) ของฝั่งคนขับว่าแสดงผลอย่างถูกต้องตามโครงสร้างนี้:

- **ปัญหาความปลอดภัย** → _เร่งด่วน (HIGH)_
- **การล่วงละเมิด** → _เร่งด่วน (HIGH)_
- **การฉ้อโกง** → _เร่งด่วน (HIGH)_
- **ข้อพิพาทการชำระเงิน** → _ปกติ (NORMAL)_
- **ลืมของ** → _ปกติ (NORMAL)_
- **ผู้โดยสารไม่มา** → _ไม่เร่งด่วน (LOW)_
- **พฤติกรรมไม่เหมาะสม** → _ไม่เร่งด่วน (LOW)_
