# User Manual 
## Product Backlog Item No.16 (Delete Account)
### User Delete Account (Passenger / Driver)

# User Story: As a User, I want to delete my account so that I can permanently remove my data from the system when I no longer wish to use the service.

# การใช้งานสำหรับผู้ใช้งาน (User)

เอกสารฉบับนี้อธิบายขั้นตอนการลบบัญชีผู้ใช้งาน (Delete Account) เพื่อให้ผู้ใช้งานสามารถจัดการข้อมูลส่วนตัวและยกเลิกการใช้งานระบบได้อย่างปลอดภัย

1. เข้าสู่หน้า User Menu
    1.1 เข้าสู่ระบบ (Login) ให้เรียบร้อย
    1.2 ที่หน้า Dashboard ให้มองไปที่มุมขวาบน
    1.3 คลิกที่ชื่อผู้ใช้งาน (User Profile)

2. เข้าสู่หน้าบัญชีของฉัน (My Account)

    2.1 หลังจากคลิกชื่อผู้ใช้งาน จะมี Dropdown แสดงขึ้นมา
    2.2 เลือกเมนู "บัญชีของฉัน" (My Account)
    2.3 ระบบจะพาไปยังหน้าจัดการข้อมูลโปรไฟล์

3. เข้าสู่เมนูลบบัญชี (Delete Account)

    3.1 ในหน้าบัญชีของฉัน ให้เลื่อนลงมาด้านล่าง
    3.2 จะพบหัวข้อ "ลบบัญชี" (Delete Account)
    3.3 คลิกปุ่ม "ลบบัญชี"

4. อ่านคำเตือนก่อนลบบัญชี

ระบบจะแสดงข้อความแจ้งเตือน โดยมีรายละเอียด เช่น:
    4.1 ข้อมูลบัญชีทั้งหมดจะถูกลบถาวร
    4.2 ประวัติการใช้งานจะไม่สามารถกู้คืนได้
    4.3 การสนทนาและข้อมูลต่าง ๆ จะหายไปทั้งหมด

# ⚠️ ผู้ใช้งานควรตรวจสอบให้แน่ใจก่อนดำเนินการ ⚠️

5. ยืนยันการลบบัญชี

    5.1 ระบบจะมีช่องให้กรอกข้อมูลเพื่อยืนยัน (เช่น รหัสผ่าน)
    5.2 กรอกข้อมูลให้ถูกต้อง
    5.3 กดปุ่ม "ลบบัญชี" (Delete Account)

# หลังจากลบบัญชีแล้ว ระบบจะยังคงเก็บข้อมูลไว้ชั่วคราวเป็นระยะเวลา 90 วัน
# หากเกิน 90 วัน แล้ว ระบบจะทำการลบข้อมูลทั้งหมดแบบถาวร

# สรุปการทำงานของระบบ

ระบบ Delete Account ถูกออกแบบมาเพื่อให้ผู้ใช้งานสามารถควบคุมข้อมูลของตนเองได้ 

โดยผู้ใช้งานสามารถ:
    ลบบัญชีได้อย่างปลอดภัยและมีขั้นตอนชัดเจน
    ได้รับคำเตือนก่อนดำเนินการ
    เก็บข้อมูลไว้ชั่วคราวเป็นระยะเวลา 90 วัน

มั่นใจได้ว่าหลังครบกำหนด ข้อมูลจะถูกลบอย่างถาวร
