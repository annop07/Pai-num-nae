# การประกาศการใช้ปัญญาประดิษฐ์ (AI Declaration)

รายงานฉบับนี้ได้นำปัญญาประดิษฐ์มาเป็นเครื่องมือช่วยในการพัฒนา โดยมีรายละเอียดดังนี้

**เครื่องมือที่ใช้:** Claude Sonnet (เครื่องมือหลัก), GitHub Copilot

**ขั้นตอนที่นำปัญญาประดิษฐ์มาใช้**

1. **วิเคราะห์โครงสร้างและองค์ประกอบของโปรเจกต์** — ใช้เป็นแนวทางในการออกแบบและวางแผนการพัฒนา
2. **ตรวจสอบและแก้ไขข้อบกพร่อง (Bug Fixing)** — ช่วยวิเคราะห์สาเหตุของข้อผิดพลาดและเสนอแนวทางแก้ไข
3. **Review Code** — ช่วย Review Code หลังจากทำการเขียนเสร็จสิ้นและถ้าต้องแก้ไขอะไรต้องเสนอแนวทาง

ทั้งนี้ ผมได้ความถูกต้องและทดสอบ แก้ไขผลลัพธ์ที่ได้จากปัญญาประดิษฐ์ทุกส่วนด้วยตนเอง เพื่อให้มั่นใจในความถูกต้องและความเหมาะสมก่อนนำไปใช้งานจริง
