# User Manual
# Product Backlog Item Bonus (Payment)
# User Generate Payment (Passenger / Driver)
# User Story:

# As a User, I want to generate and download a receipt/invoice so that I can keep it as proof of payment and use it for financial records.

การใช้งานสำหรับผู้ใช้งาน (Passenger / Driver)

# เอกสารฉบับนี้อธิบายขั้นตอนการออกใบเสร็จ/ใบกำกับภาษี (Payment) เพื่อให้ผู้ใช้งานสามารถนำไปใช้เป็นหลักฐานการชำระเงินได้

1. เข้าสู่เว็บไซต์

1.1 เข้าเว็บไซต์ของระบบ
1.2 ทำการ Login เข้าสู่ระบบ

2. เข้าสู่หน้า Profile

2.1 ไปที่เมนู Profile
2.2 กดที่ชื่อผู้ใช้งานด้านขวาบน
2.3 ระบบจะแสดง Pop-up เมนู

3. เข้าสู่เมนูตรวจสอบการชำระเงิน

3.1 เลือกเมนู "ตรวจสอบการชำระ/ชำระเงิน"
3.2 ระบบจะแสดงรายการธุรกรรมของผู้ใช้งาน

4. เลือกรายการที่ต้องการออกใบเสร็จ

4.1 เลือกรายการชำระเงินที่ต้องการ
4.2 ระบบจะแสดงรายละเอียด เช่น:

 วันที่ชำระเงิน
 จำนวนเงิน
 สถานะการชำระเงิน

5. สถานะรอการยืนยัน (Pending Verification)

5.1 หลังจากผู้ใช้งานทำการชำระเงิน ระบบจะขึ้นสถานะ "รอการยืนยัน"
5.2 ระบบจะรอการตรวจสอบจาก Driver
5.3 Driver จะทำการตรวจสอบ:

 หลักฐานการโอนเงิน
 ความถูกต้องของจำนวนเงิน

5.4 เมื่อ Driver ยืนยันแล้ว สถานะจะเปลี่ยนเป็น "ยืนยันแล้ว"

6. กรอกข้อมูลสำหรับออกใบเสร็จ

6.1 กรอก ชื่อ-นามสกุล / ชื่อบริษัท
6.2 กรอก ที่อยู่
6.3 กรอก เลขประจำตัวผู้เสียภาษี (ถ้ามี)
6.4 ตรวจสอบข้อมูลให้ถูกต้อง

7. ออกเอกสาร (Generate Receipt)

7.1 สามารถกดปุ่ม "ออกเอกสาร" ได้เมื่อสถานะเป็น "ยืนยันแล้ว" เท่านั้น
7.2 กดปุ่ม "ออกเอกสาร"
7.3 ระบบจะสร้าง ใบเสร็จ / ใบกำกับภาษี ให้โดยอัตโนมัติ

8. ดาวน์โหลดหรือแสดงเอกสาร

8.1 ระบบจะแสดงตัวอย่างเอกสาร (Preview)
8.2 ผู้ใช้งานสามารถ:

 ดาวน์โหลดเป็นไฟล์ PDF
 หรือบันทึกเก็บไว้ในระบบ

9. ระบบนำไปยังหน้าประวัติเอกสาร

9.1 หลังจากออกเอกสาร ระบบจะพาไปยังหน้าประวัติ
9.2 ผู้ใช้งานสามารถตรวจสอบย้อนหลังได้

# สรุปการทำงานของระบบ
# ระบบออกใบเสร็จ/ใบกำกับภาษีถูกออกแบบมาเพื่อให้ผู้ใช้งานสามารถจัดการเอกสารทางการเงินได้สะดวก โดยผู้ใช้งานสามารถ:

ตรวจสอบรายการชำระเงินย้อนหลัง

รอการยืนยันการโอนเงินจาก Driver

ออกใบเสร็จ/ใบกำกับภาษีได้เมื่อได้รับการยืนยัน

ดาวน์โหลดเอกสารเพื่อใช้งานได้ทันที

เก็บประวัติเอกสารไว้ในระบบ
